# Contributing

This repository is a research artifact: the manuscript, the pipeline and the result
files must stay consistent. The checks below are cheap; run them before every commit.

## Setup

```bash
uv sync --extra dev
uv run pre-commit install
```

## Before a pull request

```bash
make check          # ruff + pytest + manuscript structural check
```

For changes that touch the numerical pipeline, also run:

```bash
make all            # regenerate tables and figures from the archived snapshot
git diff --exit-code data/processed docs/JOURNAL.md
```

If a numerical result changes intentionally, update the manuscript prose and re-bless
the golden hashes:

```bash
uv run python -m stillwar tables --bless
```

## Rules

- **Never patch `data/raw/`.** Add a new snapshot and a new SHA-256 manifest instead.
- **Keep result JSONs numeric.** Formatting belongs in `stillwar.reporting`.
- **Edit prose outside the table markers.** Tables between `<!-- BEGIN TABLE n -->`
  and `<!-- END TABLE n -->` are generated by `make tables`.
- **Add a test for every new invariant.** Mathematical properties belong in
  `tests/test_kkt_theorem.py` or `tests/test_levy_area.py`; artifact contracts belong in
  `tests/test_provenance.py`.
- **Import from packages, not shims.** New code uses `stillwar.config`,
  `stillwar.data`, `stillwar.features`, `stillwar.models`, `stillwar.optimization`,
  `stillwar.backtest`, `stillwar.experiments`, `stillwar.reporting` and
  `stillwar.provenance`. The top-level modules are compatibility shims.
- **Keep the package boundary.** Reporting reads JSON artifacts; it never re-simulates.
