# When the Optimizer Refuses to Trade

Manuscript source for **“When the Optimizer Refuses to Trade: A KKT No-Trade Zone
and Lévy-Area Signal Activation under Weak Signals in LQ45 Equities”**.

The Markdown file is the source of truth. The Word/PDF files are generated
artifacts and are intentionally ignored by Git.

## Verify the manuscript

```bash
python tools/check_manuscript.py
```

The check fails on any surviving editorial placeholder, ragged Markdown table,
missing or uncited reference, or missing figure.

## Reproducibility

The empirical results in the manuscript are generated by the replication
pipeline archived at
[`raindragon14/Stillwar`](https://github.com/raindragon14/Stillwar), release
`v1.0.0` (result artifacts from git SHA `870f93a`). That repository contains the
raw OHLCV snapshot with its SHA-256 manifest, the 1,225-trial Deflated-Sharpe
grid, the trained checkpoints and the table/figure generators. This repository
versions the manuscript source and the two figures it displays.

The numbers in the manuscript were copied from the release artifacts
(`table1.json`, `table2.json`, `table3.json`, `phase4.json`, `gate_weights.json`
and `forecasts_lstm.npz`), not re-estimated for this repository.
