# Reproducibility

This repository is a research artifact: the manuscript, the pipeline and the result
files must stay consistent. The checks below are cheap; run them before every release.

## Environment

- Python **3.14** (`pyproject.toml`, `.python-version`).
- Dependencies are pinned in `uv.lock`; `uv sync --extra dev` creates the environment.
- `Dockerfile` pins the OS-level image for a clean-machine run.
- `.devcontainer/` provides the same environment in VS Code.

## Data

- `data/raw/` is the archived Yahoo Finance snapshot; `data/raw/manifest.sha256`
  records every file's SHA-256. `python -m stillwater verify` checks it before any panel
  is built.
- Missing or suspended stock-days carry the last adjusted price forward and set volume
  to zero; they are never filled from later dates.
- `make ingest` exists only to fetch missing files; the archived snapshot is the source
  of truth.

## Pipeline

| Stage | Output |
|:--|:--|
| `verify` | manifest check |
| `features` | order-2 log-signature dataset (`.cache/dataset`) |
| `train` | checkpoints + forecast arrays |
| `baselines` | Hist-MV and GMV forecast arrays |
| `simulate` | Tables 1–3, KKT log, Phase-4 diagnostics |
| `experiments` | structural-extension artifacts |
| `trials` | 1,225-trial Deflated-Sharpe distribution |
| `figures` | manuscript figures in `reports/figures` |
| `tables` | Tables 1–3 synced into `docs/JOURNAL.md` |

`make all` runs the main pipeline; `make trials` is separate and takes about 20 minutes.
`dvc.yaml` describes the same stages for reviewers who prefer `dvc repro`.

## Determinism

- Five pinned seeds (0–4); torch is pinned to one thread; deterministic kernels are
  requested where available.
- Expensive stages use a content-addressed cache keyed on config, code and input
  digests; `--force` bypasses it.
- Result JSONs contain numbers, never pre-formatted strings. Tables are rendered from
  those numbers and compared cell-by-cell with `docs/JOURNAL.md`.
- `tests/golden_values.json` stores the numeric payloads; the golden test compares
  floats with a relative tolerance of `1e-6`.

## Artifacts

- `data/processed/*.json` — provenance-stamped tables and diagnostics.
- `data/processed/exp_short_circuit_equivalence.json` — the short-circuit versus
  full-solve decision agreement behind the claim of Section 2.6 and Appendix A.4.
- `models/checkpoints/` — frozen per-seed weights.
- `reports/figures/fig1_kkt_spread.*`, `reports/figures/fig2_trigger_decomposition.*` —
  the two figures used by the manuscript.
- `reports/figures/figS1_architecture.*`, `reports/figures/figS2_sensitivity.*` are
  supplementary outputs generated by `make figures`; they are ignored by Git.

## Known limits

- Last-bit floating-point differences across BLAS/SciPy builds can move a result by
  about `1e-6`; the manuscript tables are unchanged and the golden test tolerates that
  difference. For byte-identical artifacts, use the Docker image with the pinned
  `uv.lock`.
- PNG bytes can differ across matplotlib/font builds even when the plotted data are
  identical.
- `make trials` is expensive; its output is committed so the Deflated Sharpe column is
  reproducible without a 20-minute rerun.

## Commands

```bash
uv sync --extra dev
uv run python -m stillwater verify
make all                 # main pipeline
make trials              # 1,225-trial DSR grid, once
make check               # ruff + pytest + manuscript check
```
